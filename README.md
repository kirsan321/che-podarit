# che-podarit

"Che Podarit" - a wishlist app with two roles: Recipient (keeps one permanent wishlist, shares it by link) and Giver (sets occasion and budget, swipes through the recipient's wishes, picks a gift, the gift gets reserved so nobody duplicates it).

Mobile-first PWA, no native clients.

## Status

Project kickoff: 2026-09-14. Target for MVP: 2026-10-14.
